# Дело о цепной арке

Интерактивная страница к домашней работе № 3 по дисциплине «Несущие системы зданий и расчетные модели»
(НИУ МГСУ, ИПГС, 2026). Трёхветвевая арка по цепной линии z = 250 − 80·ch(x/80), высота 170 м, расчётная
модель собрана в SCAD через текстовый формат исходных данных.

**Открыть страницу:** https://darkezz8.github.io/Arch-Lab-DR3-KuldyaevFS/

На странице:

- 3D-модель арки (три ветви, полые квадратные сечения, закрутка 0…90°) — вращается мышью или пальцем;
- расследование: почему цепная арка гнётся — постоянное сечение, ось по линии давления (итерации), почти нерастяжимая арка;
- лаборатория: 13 расчётов в SCAD с разным размером полости — вес, сжатие, растяжение в углах сечения;
- материалы для скачивания: отчёт и лист чертежа (PDF), расчётная схема в текстовом формате SCAD, сечения «Консула», результаты экспериментов.

| Файл | Что это |
|---|---|
| `index.html`, `style.css`, `charts.js`, `app.js` | Страница |
| `data.js` | Результаты расчётов для графиков и 3D-модели |
| `files/arka_dr3.txt` | Расчётная схема SCAD (кодировка Windows-1251): «Файл → Прочитать проект из текстового формата»; файлы сечений — из `files/sechenia.zip` в папку `sechenia` рядом |
| `files/sechenia.zip` | Сечения: DXF (AutoCAD), CON и CNS («Консул») |
| `files/otchet_DR3.pdf`, `files/DR3_list1.pdf` | Отчёт и лист чертежа |
| `files/eksperimenty.json` | Результаты расчётных экспериментов |
| `img/` | Снимки окна SCAD и лист чертежа |

Расчёт — SCAD Office 21.1.9.9, линейная постановка; нормы — СП 20.13330.2016 (снег, прил. Б.2), СП 63.13330.2018 (бетон В50).
